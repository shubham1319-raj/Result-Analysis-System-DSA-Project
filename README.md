# Result Analysis System

## Project Description
A Java-based console application to manage and analyse student examination results.

## Technologies Used
- Java
- ArrayList
- HashMap
- Insertion Sort
- Searching
- File Handling

## Features
1. Add student results.
2. Calculate total marks, percentage and grade.
3. Search students by name.
4. Generate student rank lists.
5. Find topper and class average.
6. Save and load records using a text file.

## How to Run
1. Install Java JDK.
2. Open the project folder in VS Code.
3. Compile:
   `javac ResultAnalysisSystem.java`
4. Run:
   `java ResultAnalysisSystem`

## Data Storage
Student records are stored in `results.txt`.
